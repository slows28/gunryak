군략 | 안정성 검증판 v0.4
=================================================

[기존 프로젝트가 있다면 삭제/재설치 불필요]
- 현재 gunryak 폴더에 압축파일의 gunryak 내부 파일들을 덮어써서 업데이트할 수 있습니다.
- Godot 프로젝트 매니저에서 새 프로젝트를 만들 필요가 없습니다.

[처음 설치하는 경우]
1. ZIP 압축을 풉니다. 안쪽의 gunryak 폴더가 프로젝트 폴더입니다.
2. Godot 4.x 프로젝트 매니저에서 '가져오기'를 클릭합니다.
3. gunryak/project.godot 파일을 선택합니다.
4. '편집'으로 프로젝트를 열고 F5를 누릅니다.

[화면 조작]
- 전투 시작 전: 오른쪽 장수 3명 선택 → 작전 목표 / 진형 운영 방침 선택 → 초기 작전 설정
- '전투 개시' 버튼 클릭 → 양군 자율 이동·전투 진행
- '일시정지', '속도 ×2', '초기화' 버튼 이용
- 오른쪽 '책사 지휘 위치' 전선 접근 / 본진 복귀로 책사 위치 이동
- 6턴부터 새 명령을 '전령 보내기'로 전달 (도착해야 적용)
- 지도에서 아군 부대 클릭하여 상황 확인

[포함된 실험 기능]
- 아군 3 / 적군 3개의 장수별 보병·궁병·기병 부대
- 신중·균형·공격 성향에 따른 간단한 자율 행동 분기
- 횡대·종대·방진 진형 변경에 실제 시간 소요, 화면상 위치와 이동·교전 계산 일부 반영
- 전투부대 위치를 고려한 자동 보급기지 이전 및 영향권, 미보급 페널티
- 2턴과 4턴에 각 진영 본진으로 제한된 보병 예비부대 도착
- 6턴 이후 이동 시간이 필요한 전령, 책사 전진 이동, 책사 포획 패배
- 승패/시간 종료, 전황 로그, 일시정지/배속/재설정

[설계 한계 / 미구현]
- 완성작이나 정밀한 삼국지 시나리오가 아니라 2D 전투 엔진의 초기 플레이 검증용입니다.
- 장수 판단은 규칙 기반이며 세부 정찰, 다단계 전술, 개별 병사의 충돌 AI는 없습니다.
- 지도는 고정이며 숲은 감속만 적용합니다. 장애물 회피용 경로 탐색은 현재 없습니다.
- 진형은 12개 병사 마커, 교전 피해/이동 수정에만 일부 반영한 실험 모델입니다.
- 정상적으로 전투가 종료되는 시간 제한(최대 180초)은 강제 종료/크래시와 별개의 게임 규칙입니다.
- 본 버전은 별도 Godot 실행 바이너리가 없는 환경에서 제작되어 사용자 PC에서 최종 검증이 필요합니다.

[중요: 충돌/크래시 발생 시]
- Godot 편집기에서 F5 실행 → 게임 창이 종료되면 하단 '디버거 > 오류' 또는 '출력' 확인.
- 우선 화면의 오류 텍스트를 그대로 복사해 보내주세요.
- 재발 시 diagnostic.tscn을 연 뒤 F6으로 실행해 10초 이상 유지되는지 점검하면 엔진/렌더링 문제와 전투 스크립트 문제를 구분할 수 있습니다.
- 프로젝트 구조는 scripts/war_sim.gd(계산) 및 scripts/game.gd(화면)로 분리되어 있습니다.

[개발자 테스트]
Godot CLI가 있는 환경에서는:
  godot --headless --path <gunryak폴더> --script res://tests/smoke.gd

버전: 0.4 · 프로젝트에 필요한 정적 검사만 직접 실행했으며 실제 Godot 실행 검증은 미완료입니다.
