# 강 위의 파수
군략을 위해 쓴 40마디의 라단조 실내악곡이다. 플루트와 비올라가 선율을 주고받고 첼로, 하프와 현악 합주가 받친다. 편집 가능한 악보는 river_watch.mid, 게임용 스테레오 음원은 assets/audio/river_watch.ogg에 있다.

MIDI는 Frank Wen의 FluidR3 GM 음색으로 렌더링했다. 배포 시 동봉하는 음색 저작권 고지는 FluidR3-COPYRIGHT.txt에 있다. 전투 및 전령 효과음은 이 프로젝트를 위해 별도로 합성했다.

## 상황별 악곡

| 상황 | 곡 | 편성 및 전환 조건 |
|---|---|---|
| 타이틀·출전 편성·작전 지도·중간회의 | 강 위의 파수 | 기존 플루트·비올라 실내악을 반복한다. |
| 낮 행군 | 먼 길의 발걸음 | 오보에 주제에 첼로가 두 박의 보행을 받친다. 전장이 조용한 낮에 연주한다. |
| 밤 야영 | 등불 아래 | 낮은 첼로와 하프 사이로 플루트가 길게 숨을 쉰다. 해질녘과 새벽에 서로 다른 전환 문턱을 둔다. |
| 교전 | 맞붙은 전열 | 비올라의 짧은 동기와 호른의 응답을 쓴다. 아군이 양 끝을 관측한 실제 타격이 발생하면 시작하고 마지막 타격 후 8초간 유지한다. |
| 본진 피습 | 성문 아래 | 바순·저현의 끊어진 리듬으로 본진 점거가 시작됐음을 알린다. 점거가 멎은 뒤 6초간 여운을 남긴다. |
| 승리 | 귀환 | 호른과 플루트가 장조 종지로 마무리한다. 결과 화면에서 한 번 연주한다. |
| 패배·철수 | 빈 진영 | 첼로의 하행 선율을 오보에가 받는다. 결과 화면에서 한 번 연주한다. |

야영 중 교전이 관측되면 교전곡, 아군 본진 점거가 시작되면 위기곡이 우선한다. 작전 지도와 중간회의 중에는 회의곡을 사용한다. 일반 일시정지·전령 열람은 그 시점의 곡을 이어간다. 전환 길이는 2.4초다. 전장의 게임 속도와 별개로 페이드되며 음향 전환은 음악·전투음·경보에 함께 적용된다.

새 여섯 곡은 군략을 위한 창작곡이다. `python3 audio_source/arrange_field_score.py`로 편집 가능한 MIDI 여섯 개를 재생성한다. 배포 음원은 기존 곡과 같은 FluidR3 GM으로 렌더링한 44.1kHz 스테레오 Ogg Vorbis다. 순환곡에는 마디 끝의 잔향을 앞부분에 겹쳤고, 승전·패전곡에는 독립된 종지와 잔향을 남겼다.

Godot 임포트 후 `godot --headless --audio-driver Dummy --path . --script res://tests/field_score.gd -- /tmp/gunryak-score.wav`로 일곱 상황을 전환하면서 게임 마스터 출력의 시연 파일을 생성한다.
